# Debug-ключ приложения

`uchus-debug.keystore` — общий **отладочный** ключ для локальной сборки и
GitHub Actions.

Зачем он нужен: Android не установит APK поверх приложения, подписанного другим
ключом. Если локальная сборка и CI используют разные debug-ключи, обновление с
сайта не установится. Общий ключ делает все debug-APK совместимыми.

Параметры (стандартные для debug):

```text
alias:  androiddebugkey
пароль: android
```

Это **не** ключ для Google Play. Для публикации в магазине создайте отдельный
release-ключ и настройте `signingConfig` для `release`. Debug-ключ не является
секретом и не даёт доступа к аккаунтам пользователей.
