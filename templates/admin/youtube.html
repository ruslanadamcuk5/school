⏩ Подобрать видео заранее

YouTube даёт около 10 000 units в день, а один поиск стоит примерно 100 units. Поэтому за запуск обрабатывается не больше 5 тем. Кэш обновляется автоматически при просмотре темы.

🔑 Как получить ключ

  1. Откройте Google Cloud Console → YouTube Data API v3 и нажмите «Enable».
  2. В разделе «Credentials» создайте API key.
  3. Ограничьте ключ: API — YouTube Data API v3, при желании — по IP сервера.
  4. Вставьте ключ в поле выше и сохраните настройки.
